## 二、数据完整性（TC-DATA）

### TC-DATA-001 · 记录「经期结束日」后生理节律推算实时更新 ⭐本次重点
- **优先级**：P0 · **类型**：数据/逻辑 · **预估**：6 min
- **准备**：已装 v1.4.5；`CyclePhaseCard.handleSaved` 已修复为 `loadPeriodDays()` 重载（旧版仅 `loadCycleLog`，导致 periodEnd 不刷新）。
- **执行**：
  1. 在周期记录面板勾选「经期结束于这一天」并保存；
  2. 返回洞察页「生理周期节律」月相环卡 / 回顾页「生理周期」区；
  3. 观察相位、关键日期、周期第 N 天是否同步收口。
- **断言**：经期段被 `derivePeriodRuns` 强制收口；月相环相位、回顾页「周期第 N 天」「经期里/外」提示均立即反映结束日；不再把已结束经期算作「经期里」。
- **通过/失败**：✅ 代码走查通过（修复已编入 build）；回顾页已正确渲染「周期第 5 天 / 经期里」推算结果（见截图）。真机勾选保存 E2E 待手动补。
- **潜在缺陷（已修）**：修复前 `CyclePhaseCard.handleSaved` 不重载 `periodDays`，是用户反馈「记录经期结束但推算没更新」的根因。

### TC-DATA-002 · 洞察页血压卡标题字号与 HRV/血氧统一 ⭐本次重点
