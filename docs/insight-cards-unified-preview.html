统一卡片 · 设计规范
卡片外壳白底 #FFFFFF · 圆角 18px · 1px 描边 rgba(31,29,26,.09) · padding 15–16px
头部左侧 = 26px 圆角图标方（skySoft 底 + skyDeep 图标）+ 名称（14px/600）；右侧 = 状态 pill（实时/已测/待接入）
主数值24px/600 黑字 + 单位（13px/soft）；下方一行范围提示用 skyDeep
配色铁律血压 / 血氧 归蓝（sky）家族：血压 收缩 skyCore、舒张 skyMid；血氧趋势线强制 skyCore（修掉哈希随机色）。心电是唯一用红的模块——波形 / 图标 / 入口 / 按钮全部 ecgRed #E5484D（专业心电惯例，线必为红，与 anomaly 异常红 #E2554E 解耦）
心电专属迷你波形 + 心率/HRV/呼吸 三格 + 「重新测量」按钮（全 App 统一渐变 →，字 ）
底部入口全卡统一「查看趋势图 ›」行（skyDeep 字 + skyCore 箭头），点卡片进日/周/月/年趋势详情
空态无数据 → 图标 + 名称 + 「点击查看」+ 底部「查看趋势图 ›」保持不变，不显示数值
