④ 折叠组件统一标准（mhRow = App moreHead）

详细数据 / 逐周期明细 / 查看完整症状分布 / 展开更多指标▾

横轴统一规范

周=周一→周日全标；月=固定刻度(1/5/10/15/20/25/月末)；年=固定刻度(1/3/6/9/12月)。单一事实来源 src/lib/chartAxis.ts。经期/周期类图表按「周期月/周/年」口径，刻意不并入自然周月年。详见 axis-unified-preview.html。
