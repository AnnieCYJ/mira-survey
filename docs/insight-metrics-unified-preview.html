统一规范 · 组件与 Token

通用外壳（全部 5 板块共用）

  • 白卡 border-radius:18px + 1px 描边 + 浅投影；容器 max-width:420px。
  • 范围切换 .switch 滑动药丸（日/周/月/年），与睡眠/脑力/压力预览同壳。
  • 折叠入口统一 mhRow（= App moreHead：浅底描边行 + 左标签 + 右 chevron，160ms 旋转）。
  • 图表均有纵轴（带单位）+ 横轴刻度；无数据时诚实显示占位。

各板块系列 Token（禁止混用）

  • 血压：收缩 #7EA6F8 / 舒张 #B9CCF9（蓝，心肺语义）。
  • 血糖：#E5A53B（琥珀，对齐洞察页血糖卡 honeyDeep）。
  • 激素指标：状态指数紫 #7C6AE0；皮质醇异常红 #E2554E；周期相位亮绿 #BCCB62。
  • 心电：心肺蓝 #7EA6F8（与血压同源，区分于紫）。
  • 身体成分：状态 pill 正常绿 / 偏高红 / 偏低琥珀，与全局状态色一致。

详细分析块（血压/血糖/激素指标 共用，与全天状态趋势同款）

  • 第一排：平均 / 最高 / 最低（本区间统计值，与曲线同源）。
  • 第二排：对比上周 / 对比30天基线（带 ▲/▼ delta 百分比）。
  • 激素指标额外有：状态最好 / 状态最差（周/月/年显示）。
  • 心电/身体成分无「详细分析」块（数据形态不同：单次测量 / 体检报告）。
预览即设计稿：确认后血压/血糖补「详细分析」块 + 统一 token，心电/身体成分仅外壳对齐；激素指标(全天状态趋势)基本已符合，仅轻微核对。所有改动零新增 tsc 错误（基线 42）。
