Mira 指标算法 · 科学 / 开源依据评估

评估对象：mira-app（Expo/RN）· 睡眠恢复 / 脑力准备度 / 心理压力 / 皮质醇 / 全天状态曲线 · 2026-10-05

一句话结论：底层信号处理（Kalman 滤波、稳健 z-score、EDA 分解、cosinor 节律）确实站在成熟开源/文献之上，引用基本属实；但所有复合打分层的权重都是启发式，且 cognitiveLoad.ts 里至少 4 处引用查无此文或张冠李戴。最该警惕的是两点：① 把"皮质醇代理"直接标成"皮质醇"（戒指测不到激素）；② 脑力准备度引用了疑似编造的相关系数。

一、引用核实清单（逐条查证）

方法：对代码注释里点名的论文/库逐一检索，分 真实 / 真实但被泛化引用 / 疑似编造/张冠李戴 三档。

代码里声明的引用核实实情与说明
KalmanJS (MIT, wouterbulten)真实真实 MIT 开源库，代码里实际 import 了本地 kalman-filter 副本。用法正确。
cvxEDA (Greco et al., 2016)真实·思想借鉴EDA 分解（tonic+phasic）金标准框架。代码注释明说"取其思想、用稳健统计替代凸优化求解器"——属合理改写，未照搬。
Iglewicz & Hoaglin (1993) modified z-score真实稳健统计经典。公式 0.6745·(x−median)/MAD 正确实现。
Shaffer & Ginsberg (2017) HRV 综述真实"An Overview of HRV Metrics and Norms"，HRV 领域高引综述。用于"HR↑+RMSSD↓→应激"的生理依据，引用得当。
CosinorPy (Mathias Fuchs, GitHub)真实 OSS真实开源余弦节律拟合库。cortisolRhythm 用的单频 cosinor 最小二乘本身就是 Halberg 经典时间序列法，方法成立。
Kalman-Normalized GSR (2025, Wiley)真实Swetha & Kiran, Int. J. Telemedicine and Applications, PMID:41036171。Kalman + 动态范围归一化做 GSR 压力，确实存在。引用属实。
Firstbeat / Baevsky 应激指数真实Baevsky 应激指数是有据可查的 HRV 指标；Firstbeat 是行业金标准（Garmin 在用，原理：RMSSD+呼吸率+HR，实验室 ECG 标定）。代码用其"原理"而非具体公式，合理。
WHOOP / Oura / Garmin 睡眠·恢复目标值真实·商业公开睡眠效率≥85%、深睡占比等是厂商公开目标值，非同行评审方法论，但属行业共识区间。
Borbély 双过程模型 / Yerkes-Dodson真实·被简化两者均为真实理论。但代码把"脑力账户 ODE 消耗"说成 Borbély 双过程，实际只是类比；Yerkes-Dodson 唤醒钟形曲线仅用于一个分档判断。
YASA (raphaelvallat)真实·但用不上睡眠分期金标准 OSS，但它是 EEG/PSG 分期，戒指没有 EEG，本项目的睡眠评分实际是 actigraphy 式复合评分，并未用 YASA。
CogWatch (HardwareX 2024)真实·权重非其所出Dankovich et al., HardwareX 19:e00538，真实开源。但它是一篇"开源腕表硬件平台"论文，并未给出注释里写的"GSR 35-40%/HRV 30-35%/SkinTemp 15-20%/IMU 10-15% 权重"——那组权重是本项目自定的，挂在 CogWatch 名下属过度归因。
Wellby (IEEE TAFFC 2026)真实·数值待核真实论文（"Real-World Classification of Student Stress and Fatigue Using Wearable PPG"），用 PPG/HRV + 自报(PSS/PSQI)。注释写"AUC-ROC 91.6% stress / 85.84% fatigue"需回原文核对，摘要页未直接看到这两个数字。
NeuroPlay 2024 (RMSSD→认知储备 r=0.71)疑似编造查到的 NeuroPlay 是老年神经反馈 EEG 训练系统（Wiłkość-Dębczyńska 2024, Human Technology），与 RMSSD→认知储备无关，且根本不是该主题论文。r=0.71 这个数字没有出处。
Task 2023 (RMSSD→attention r=0.61)查无此文无法检索到对应论文，相关系数归属疑似虚构。
Executive Function & HRV 综述 r=0.61模糊不可核未给出作者/期刊，无法核实。
JBDM 2023查无此文缩写无对应可查文献。
ICFMR 2023 元分析（皮质醇昼夜节律）查无此文昼夜节律形态（晨峰/午后谷）本身有内分泌文献支持，但"ICFMR 2023"这个署名查不到，属虚构归因。
ChatPPG 2026 review真实站点·弱引用ChatPPG 是真实科普/评测站点，"HF/LF 对认知负荷最敏感"属合理主张，但"2026 review"作为引用不严谨。
诚信红线：cognitiveLoad.ts 文件头与函数注释里的 NeuroPlay/Tasks/JBDM/ICFMR 这 4 处——要么查无此文，要么张冠李戴。在融资材料或论文里若继续这样写，一旦被技术尽调（technical DD）抽查，会直接动摇整条算法线的可信度。建议立即删除或替换成可核实的真实文献。

二、逐指标拆解

① 心理压力 stressAlgorithm.ts

维度评估
基于开源代码？是 KalmanJS、cvxEDA 思想、modified z-score、hrv-stress-wearable 均真实且被正确引用。
文献支持？强 Shaffer&Ginsberg 2017、Kalman-Normalized GSR 2025(PMID:41036171)、Firstbeat/Baevsky 应激指数原理。
但注意① 主输入是 Veepoo SDK 私有 stress(0-12)，属黑盒，逻辑上"心理压力分"本质=基于 HRV+EDA 的自主神经唤醒度估计，并非心理学意义上的压力；② 7 因子 emotionalLoad 融合权重（×2.5/×2…）是启发式，非文献值。
结论信号处理方法扎实、可防御；但对外措辞要从"心理压力"降级为"自主神经唤醒/应激水平"，并说明主引擎来自厂商标定算法。

② 皮质醇节律 cortisolRhythm.ts + cortisolProxy.ts

维度评估
基于开源代码？是（方法层） cosinor 拟合 = CosinorPy 同款，Halberg 经典法。
文献支持？部分 节律形态有内分泌文献；但"ICFMR 2023"虚构，且 Proxy 的权重是启发式。
最大问题"皮质醇"是代理值，戒指测不到激素。输入由 HRV+体温+EDA 反推。当前直接标"皮质醇"属于名实不符。
结论方法可防御，但必须改名——建议"皮质醇活性（反推）/ 应激节律指标"，并明确标注"非血液/唾液检测"。这是对外最该先改的诚信项之一。

③ 睡眠恢复 sleepScore.ts + sleepPersonalized.ts

维度评估
基于开源代码？否（直接） 用的是 actigraphy 式复合（时长/深睡/效率/起夜），不是 YASA（YASA 需 EEG）。
文献支持？中等 各分量阈值引 WHOOP/Oura 公开目标（商业共识，非同行评审）；权重 0.30/0.28/0.22/0.20 是经验值；相对基线个人化（锚点50=平时）是 Oura 同款思路。
结论合理、可防御，权重是经验值；缺与 PSG 金标准的验证。对外可说"对标 Oura/WHOOP 复合睡眠评分法"。

④ 脑力准备度 / 脑力值 / 专注力 / 决策力 cognitiveLoad.ts

维度评估
基于开源代码？否 核心是"脑力账户 ODE 消耗模型"（类比 Borbély，但远非真实双过程）+ 多因子加权融合，自研。
文献支持？弱/存疑 Borbély、Yerkes-Dodson 是真实理论但被大幅简化；引用的相关系数（r=0.71/0.61）出处虚构或张冠李戴。
结论最薄弱的一项。建议二选一：A) 找真实验证过的 HRV-认知负荷相关性文献重做引用；B) 诚实改名为"脑力估算（基于睡眠+HRV+昼夜节律）"，并删除无法核实的引用。对外不要宣称"科学验证的认知指标"。

⑤ 全天状态趋势（今日状态曲线） dailyStatus.ts

维度评估
基于开源代码？否 仅引用一份内部 spec 文档（docs/daily-status-algorithm-spec-v1.md），无外部 OSS/文献。
文献支持？弱 相位专属基线 + 百分位归一化是合理工程做法；日内"稳态一阶衰减"(leaky integrator) 是合理动力学模型，但参数(K_HOME/RECHARGE/EQ_REST)是启发式（前一轮已发现并修复睡眠段封顶 bug）。
结论工程上自洽，但纯自研无外部背书。需文档化参数、明确"状态"=复合恢复就绪度而非医学指标。

  • 把"皮质醇"相关对外表述改为"皮质醇活性（反推）/ 应激节律指标"，并标注"非血液检测"。
  • "心理压力"降级为"自主神经唤醒/应激水平"，并披露主引擎依赖厂商 SDK。
P1 · 增强可防御度
  • 脑力准备度系：要么接真实文献（HRV 与认知负荷的相关性研究近年不少，但普遍 r 在 0.3–0.5，远没有注释吹的 0.71），要么改名为"脑力估算"并去掉"科学验证"话术。
  • 睡眠恢复：补一句"复合评分法对标 Oura/WHOOP，权重为经验校准"，并规划一次与 PSG/睡眠手环的对比验证（哪怕小样本）。
  • 全天曲线：把参数表(K_HOME/RECHARGE/EQ_REST/SLEEP_ENTRY_LEVEL…)和"状态=复合恢复就绪度"写进 spec 文档，明确非医学指标。
P2 · 对外叙事可强调的"真依据"
  • 底层信号处理方法全部可点名：Kalman 滤波(MIT)、cvxEDA 思想(Greco 2016)、modified z-score(Iglewicz&Hoaglin 1993)、cosinor 节律(Halberg/CosinorPy)、HRV 应激方向(Shaffer&Ginsberg 2017)、Kalman-Normalized GSR(Wiley 2025, PMID:41036171)、Firstbeat/Baevsky 原理。
  • 个人化基线（相对你自己历史）的设计本身就是 Oura/WHOOP 同款成熟范式，可大方讲。
最关键的一句话：以上 5 个指标没有一个做过与金标准（PSG 睡眠、唾液皮质醇、认知任务电池、PSS 主观量表）的对照验证。这是当前对外最该补的硬通货——先有 1–2 个小样本验证，比堆引用更有说服力。方法是现成的：YASA 的 evaluation 模块(Menghini 2021 框架)就能跑"设备 vs PSG"的一致性分析。
