洞察页「昼夜节律」卡点进来后的皮质醇趋势详情页（修正版）。
核心原则：皮质醇看「波形节律是否正常」，没有纵坐标、不做区间均值。
· 日视图 = 今日波形（绿实线）+ 14 天基线（绿虚线），无纵轴；
· 周/月/年 = 节律日历（正常绿 / 异常红）+ 节律状态，不显示「日均相对水平」之类均值。
本稿为设计预览，定稿后再整体搬进 App。

UI 设计规范 · 组件清单（修正版）

1. 页面结构

  • 顶部 RangeSwitch：日 / 周 / 月 / 年 四档，滑动药丸同壳。
  • 日面板 = 全天趋势曲线卡（今日+14天基线，无纵轴）+ 节律分析卡（2×2 摘要 + 持续性 + AI 分析）。
  • 周/月/年面板 = 节律日历（正常绿/异常红）+ 节律状态 chip + 节律小结（异常天数 / 状态 / 峰值时段）。不出现均值、柱状图、纵坐标。

2. 组件与视觉规则

  • CortisolTrendChart（日）：今日 = 绿实线，14 天基线 = 绿虚线（两者同源 chart.series.cortisol = limeMid #BCCB62，靠实/虚区分）；含睡眠阴影、峰值竖虚线+发光点+时刻标签；无纵坐标（hideYAxis）。
  • RhythmCalendar（周/月/年）：逐日（周/月）或逐月（年）着色，CAL_COLOR 语义——正常 = limeSoft 底 + limeDeep 字，异常 = danger 柔和底 + danger 字；「今日」可加紫描边（accentSolid）。
  • StatusChip：节律正常（绿）/ 持续偏高（红）/ 节律紊乱（琥珀），由异常日/月占比判定。
  • 节律小结三格：异常天数（计数，非均值）/ 节律状态 / 峰值时段（06–11 正常）。
  • 折叠入口统一 mhRow（左标签 + 右 chevron 浅底描边行），与 App moreHead 1:1。

3. Design Token（强制）

  • 皮质醇 = 亮绿 #BCCB62（今日实线 + 14天基线虚线同色）；深绿文字 #6E7A24；异常红 #E2554E；紊乱琥珀 #C8881E；正常绿 #2E9E5B。
  • 铁律：皮质醇页面全程无纵坐标；周月年不做区间均值 / 无「相对水平」，只看波形节律是否正常。
  • 主色紫 #7C6AE0 仅用于「详情 ›」与「今日」描边，绝不上皮质醇曲线。

4. App 待同步点（预览定稿后搬入）

  • 日视图：已还原 variant="sleep" 误删的 14 天基线（绿虚线）。
