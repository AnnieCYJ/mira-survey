柱状图 · 样式与配色统一规范

针对「柱状图的设计样式和颜色不统一、不在设计规范里」的专项审计，以及一套可直接落地的 Bar 规则。

审计范围：src/components · src/screens 全部柱状 / 条状元素（SVG <Rect> + View 横条）· 2026-10-09

结论：确实没统一，而且颜色这块比尺寸更严重。 全站 17 处 柱状/条状元素，圆角有 9 种（1 / 1.5 / 2 / 2.4 / 2.5 / 3 / 4 / 5 / 9）、 宽度比例有 4 套（slot×0.5 / ×0.6 / ×0.66 / flex:1）、 透明度有 5 档（1 / 0.92 / 0.9 / 0.75 / 0.55）、空数据态有 5 种画法。 更关键的是：至少 6 处柱色不在五色规范里——认知负荷柱用了「绿→黄→粉」，而规范里紫才是认知色。

二、六类问题 · 根因

① 颜色越界（最严重）

柱色不是按「语义→色相」取，而是各组件自己写死或走 theme.colors 的旧语义 key。后果：同一个"认知"语义，在认知卡是绿黄粉，在能量页是渐变绿黄蜜，在脑力区间柱又是紫。

  • 认知负荷柱：绿 #6E7A24 / 黄 #F0C46E / 粉 #C9598A（应为紫三档）
  • 睡眠分期：紫 + 蓝 + 黄跨三相（应为黄绿相同相递进 + 清醒用黄）
  • 情绪堆叠：theme.colors.state* 与 mm.colors.mood* 两套情绪色板并存
  • 症状条 / 周期条：accentSolid 紫（认知色被挪去表达身体）

② 圆角失控

9 种圆角值：1 / 1.5 / 2 / 2.4 / 2.5 / 3 / 4 / 5 / 9。 最离谱的是 EnergyDetailScreen 写了 rx={theme.radius.sm} —— radius.sm 是 卡片圆角 9，被当成柱圆角用，柱高只有几十 pt 时整根被拉成胶囊。

还有 SleepAnalysisCard 比例条 borderRadius=5，但条高只有 10 —— 等于全圆，和它自己的图例点（4）不是一套。

③ 宽度比例四套

slot×0.5（周步数）、step×0.6（能量页）、slot×0.66（情绪堆叠）、flex:1（压力直方图）。同一个"7 天柱图"，在一页里宽窄差 30%。

④ 用透明度表达"重要程度"

周步数非今日 opacity 0.55、睡眠柱 0.92、脑力区间柱 0.75。 透明度会让柱子在白卡上发灰、对比度不可控。规范应当用「同相深浅档」表达轻重，而不是降不透明度。

⑤ 空数据态五种画法

  • 睡眠双轴：不画
  • 认知卡：白 25% 色、opacity 0.08、高 2pt
  • 周步数：rgba(120,110,160,.13)、高 3pt
  • 能量页：cardBorder+'50'、高 2pt
  • 压力图：white25、opacity 0.06、高 1pt

⑥ 渐变 vs 平涂并存

能量页周月年柱用 LinearGradient（每根柱一个 gradient id，14 根就是 14 个 defs），认知卡的同类柱却是平涂。 同语义两种质感，且渐变在窄柱上几乎看不出，只增加渲染开销。

三、统一规则（Bar Spec）

总原则：柱子的颜色由「数据语义」决定，不由「它在哪个文件」决定。 同一语义在任何页面必须同色；同一张图内的多系列必须是「同相不同档」，禁止跨相拼色。

规则 1 · 语义 → 色相映射（唯一入口）

语义色相柱子取档（低 → 高 / 轻 → 重）适用
认知 / 脑力紫 purplepurpleMid → purpleCore → purpleDeep认知负荷、脑力消耗、专注度
情绪 / 压力 / 症状粉 roseroseSoft → roseMid → roseCore → roseDeep情绪堆叠、压力直方图、症状频率
运动 / 心肺蓝 skyskySoft → skyMid → skyCore → skyDeep步数、血压、血氧、运动消耗
睡眠 / 恢复 / 今日状态黄绿 limelimeSoft → limeMid → limeCore → limeDeep睡眠时长、睡眠分期、恢复分、完成度
代谢 / 能量 / 清醒黄 honeyhoneySoft → honeyMid → honeyCore → honeyDeep血糖、血脂分项、清醒段、黄体期
周期（经期）粉 roseroseMid → roseCore经期柱、经期色带、周期长度
异常 / 心电红ecgRed #E5484D / anomaly #E2554E心电波形（唯一红）、异常标记点
空 / 无数据中性mm.colors.emptyFill #F6F4F1空柱底条、无数据占位

档位用法：单系列柱 → 一律取 core；三档分级 → mid / core / deep；四档以上 → soft / mid / core / deep。 「今天 / 峰值」这类强调，用 deep，不用 opacity。

现状 · 认知负荷柱（跨三色相）
✕ 绿 → 黄 → 粉：读起来像三种不同的指标，实际是同一条曲线的三个档位
统一后 · 认知负荷柱（紫相同相递进）
✓ 紫 = 认知；深浅 = 负荷高低，一眼是「同一件事的程度变化」

规则 2 · 圆角：只留两个值

元素圆角说明
竖柱 / 堆叠柱 / 区间柱（SVG）3 pt沿用 chart.barRadius。柱宽 ≥6 时视觉一致；不要用 radius.sm(9)、radius.md(11) 这类卡片圆角
横条 / 进度条 / 比例条（View）pill（999）条高 ≤10pt 时一律全圆，不要写 3 或 5
空数据底条1 pt2pt 高的底条，圆角 1 即可
图例色块3 pt与柱体同值，图例才能当"色卡"读
硬约束：圆角不得超过柱宽的 1/2（否则变成胶囊）；也不得用 theme.radius.card/md/sm 这类为容器设计的圆角去修饰柱体。

规则 3 · 宽度与间距

柱宽 barW = clamp(4, slot × 0.6, 24)；间距 = 剩余空间均分。 即 柱占槽位 60%，全站统一，取消 0.5 / 0.66 / flex:1 三种写法。
  • 柱数 ≤ 7：barW 取上限 24，居中排布，视觉更稳
  • 柱数 8–31：barW = slot × 0.6
  • 柱数 > 31（如 24 小时 × 多天）：barW 取下限 4，间距 1
  • 堆叠柱内各段不留间隙，缝隙由描边（1pt 白）分隔，不用 gap

规则 4 · 禁止用 opacity 表达轻重

柱体透明度只允许两个值：1（实心）与 0.12（背景带 / 相位阴影）。 其余一律用色相档位（soft/mid/core/deep）表达。需要"淡一点"的背景就取 tint/soft 档，不要给 core 色加 0.55。

  • 今日 / 峰值 → deep 档，不是 opacity 1 vs 0.55
  • 睡眠阴影 / 相位带 → soft/tint 档，不是 opacity 0.92 / 0.10

规则 5 · 禁止柱体渐变

柱体一律平涂单色。取消 EnergyDetailScreen 里每根柱一个 LinearGradient 的写法 （14 根柱 = 14 个 defs，且在 6–24pt 宽的柱上看不出渐变，只增渲染成本）。 档位差异改用同相深浅档表达。

规则 6 · 空数据统一态

无数据的槽位统一画：2pt 高 · emptyFill #F6F4F1 · 圆角 1 的贴底细条， opacity 1。全站取消「不画」/「白色 0.08」/「rgba(120,110,160,.13)」/「cardBorder+50」这四种写法。 例外：未来日期仍保持"不画"（用户既有口径：不给看着像有数据的假值）。
