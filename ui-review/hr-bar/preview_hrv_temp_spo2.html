HRV / 体温 / 血氧 —— Oura 各自怎么画结论：不是所有指标都用柱状小条

查完 Oura API 与官方文档后的结论：只有心率做了「全天柱状小条」。 HRV、体温、血氧各有独立形态，照搬心率那套会错。

HRV：只在睡眠时段测，5 分钟一点，而且是叠在睡眠分期条下面的一层，不做全天图。
体温：Oura 不给绝对体温，只给「偏离个人基线的度数」，画成一条昼夜节律曲线（含黄体期整体上移）。
血氧：只在睡眠时测，白天没有曲线；给的是整夜均值 + 整夜最低值，呼吸规律性按15 分钟一格。

为什么 HRV 不能全天画：白天的 HRV 被运动、说话、环境干扰得厉害，医学上只在睡眠静止期才有意义。 Oura 的 HRV 就是「睡眠分期条的第二层曲线」，离开睡眠段的 HRV 干脆不给。
对我们的意义：HRV 详情页应该跟睡眠详情页合并成一张图（上分期 + 下 HRV），而不是单独做一个全天 HRV 页。

关键差异：Oura 明确不报绝对皮肤温度，只报「和你的个人基线差多少」。原因写在官方文档里： 白天体温被吃喝、运动、环境干扰，只有睡眠时的体温才有意义。
对我们的意义：Mira 女性周期定位，体温正是「黄体期上移」的关键信号—— 用偏离基线 + 昼夜曲线才对，写「体温 36.5°C」既不准也没信息量。

关键差异：Oura 白天不测血氧（红光红外 LED 只在判定睡眠时亮），所以血氧没有全天图， 只有夜间曲线 + 整夜均值/最低值。这对我们的意义是诚实：没数据就写「睡眠时段测量」，别画一条白天的假线。
中段那根明显掉下去的就是呼吸事件的信号——这正是它比「整夜均值 97%」更有价值的地方。
