信息结构不动，换三层皮

01
改：背景 = 海岸黄昏

整屏铺你提供的海岸照片（cover 裁切、视线中心略偏上保住地平线）；顶部 300px / 底部 340px 两段渐变压暗——保状态栏、标题、Tab 栏可读，同时淡化原图右下角「AI 生成」水印；Tab 栏本身也是磨砂玻璃，水印基本被盖住。

02
改：Oura 式透明玻璃卡片

指标 chips 与 AI 分析卡改为半透明磨砂（backdrop blur 20~26px + 细白描边 + 内高光 + 外投影），文字转白、次要文字 70%/55% 白；CTA 保留青柠渐变。玻璃质感在真机截图/录屏里最明显，HTML 预览已尽量还原。

03
改：圆环 → 半圆白弧

参考 Oura：进度弧改为白色（白色渐变弧 72% + 低透明度白轨道底 + 白色外侧柔光 + 底部桌面反射）；弧内的「状态水」整体去掉（2026-10-16 用户要求），中央白字直接坐在背景照片上（白字 + 暗色柔影）；四月相点钉在弧上保留彩色（左=排卵 / 左上=经期 / 右上=黄体 / 右=卵泡[当前，放大 + 白光晕]）——半圆场景不做 32s 公转（会转出弧外）。

04
改：chips 位置

五个指标 chips 从圆环上方移到半圆弧下方（2026-10-16 用户要求）——圆环更贴近标题，指标卡挨着图例；其余排布（账号行在上 / 标题在下 / 图例一行 / AI 卡贴 Tab / 底部 Tab 栏）与当前 App 首页一致。

落地路径：纯 CSS / SVG + 一张背景图；RN 端半圆用 react-native-svg 的 Arc 路径（A 指令），玻璃卡片用 expo-blur（BlurView）透出下层背景图，压暗用 LinearGradient 两层。本页为效果预览，无交互。
