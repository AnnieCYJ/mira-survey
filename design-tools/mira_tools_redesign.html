Mira 工具页改版探索

顶部「每日推荐牌堆」已按你的要求隐藏（首页气泡已经承担建议入口，牌堆冗余）。下面是「改善工具箱（六宫格）」+「我的建议」的四种 UI 范式，全部用 Mira 现有设计 token 还原。 你想往哪个方向走，或要我把某一种直接落到代码里，告诉我即可。
参考来源 A · App Store 分类卡 / AstroWind B · iOS 主屏磁贴 / Notion C · Linear 分区编辑（推荐） D · Apple Fitness 摘要 / Stripe
核心判断：六个工具天然落在 Mira 的三条产品主线上 —— 身体活力 / 情绪压力 / 周期节律。 当前 2×3 平铺看不出这条主线，而方案 C 把它们按维度分组，既更贴合 Mira「多维交叉」的叙事，也顺手解决了「六个图标摆一起找不到重点」的问题。 无图方案 B 还顺带解决了照片带来的包体和加载问题。
「我的建议」卡片处理
首页气泡里被你点「有用」的建议会沉淀到这里。四个方案的网格不同，但「我的建议」建议统一用同一张白卡底（下方左），避免两套视觉语言打架； 如果你想要更轻的呈现，也可以换成「看板 / 时间线」式的小胶囊（下方右）。
