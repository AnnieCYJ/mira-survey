Mira 工具箱 · 工具选择 Tab 的 3 种位置方案

真实 App 里工具页本身就在底部主 Tab Bar（首页 / 洞察 / 工具 / 我）上 —— 所以工具选择的小 icon 条不能放页面最底部，否则和主 Tab Bar 撞。下面每个手机底部都画了真实主 Tab Bar（「工具」高亮），三个方案都把工具选择 tab 移到顶部 / 大图内侧，互不抢位。全部用你工具页现有的 6 张真实照片 + 同款图片样式。
交互：手机上左右拖 / 滑；电脑上鼠标拖，或滚轮 / 方向键翻页。点上方任意 icon 也能直接切。
